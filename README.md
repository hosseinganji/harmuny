# Harmony 🎵

موزیک‌پلیر PWA (وب، اندروید، iOS و دسکتاپ) که آهنگ‌های یک یا چند کانال تلگرام را همگام می‌کند و آفلاین هم کار می‌کند.

- **بک‌اند:** Laravel 12 + Sanctum + MySQL + MadelineProto (اتصال MTProto به تلگرام)
- **فرانت‌اند:** Vue 3 + TypeScript + Pinia + Tailwind CSS 4 + vite-plugin-pwa + Dexie (IndexedDB)
- **اپ اندروید:** Capacitor با پلاگین نیتیو `LocalMusic` برای اسکن کل حافظه‌ی گوشی

## اجرا روی سیستم (توسعه)

پیش‌نیازها: PHP 8.2+، Composer، MySQL 8، Node 20+.

```bash
# بک‌اند
cd backend
cp .env.example .env            # DB_* را تنظیم کن
php artisan key:generate
php artisan migrate
PHP_CLI_SERVER_WORKERS=8 php artisan serve --no-reload   # http://127.0.0.1:8000 (۸ پروسه‌ی موازی)
php artisan queue:work --queue=default    # ترمینال دیگر: همگام‌سازی و کش آهنگ‌ها
php artisan queue:work --queue=covers     # ترمینال دیگر: دانلود کاورها در پس‌زمینه
php artisan queue:work --queue=downloads --timeout=900   # ترمینال دیگر: دانلود کامل آهنگ‌ها روی سرور (هر ۱۰ دقیقه بررسی می‌شود)
php artisan schedule:work                 # پست‌های جدید هر دقیقه

# فرانت‌اند
cd frontend
npm install
npm run dev                     # http://localhost:5173  (برای توسعه؛ درخواست‌های /api به بک‌اند پروکسی می‌شوند)
# برای استفاده از گوشی، نسخه‌ی بیلدشده خیلی سریع‌تر است:
npm run build && npx vite preview --host --port 5173
```

اولین کسی که ثبت‌نام کند **ادمین** می‌شود. بعد از آن در «مدیریت ← تلگرام»:

1. `api_id` و `api_hash` را از [my.telegram.org/apps](https://my.telegram.org/apps) بگیر و وارد کن.
2. با شماره‌ی حسابی که عضو کانال است وارد شو (کد تلگرام و در صورت نیاز رمز دو مرحله‌ای).
3. کانال را با `@username`، لینک `t.me` یا از لیست کانال‌های خودت اضافه کن. همگام‌سازی اول خودکار شروع می‌شود.

تست‌ها: `cd backend && php artisan test` (از دیتابیس `smart_music_test` استفاده می‌کند).

## راه‌اندازی روی سرور (Docker)

```bash
cp .env.example .env
# DOMAIN، APP_URL، DB_PASSWORD و DB_ROOT_PASSWORD را پر کن
docker compose run --rm app php artisan key:generate --show   # خروجی را در APP_KEY بگذار
docker compose up -d --build
```

- یک کانتینر FrankenPHP هم API و هم PWA را سرو می‌کند و **HTTPS را خودکار** (Let's Encrypt) می‌گیرد؛ دامنه باید به سرور اشاره کند و پورت‌های ۸۰ و ۴۴۳ باز باشند.
- `worker` صف (همگام‌سازی، کش آهنگ‌ها) و `scheduler` همگام‌سازی دوره‌ای را اجرا می‌کنند.
- کش صوتی، کاورها، آواتارها و نشست تلگرام در volume ‌ی `storage` می‌مانند. حجم کش با `MUSIC_CACHE_MAX_MB` محدود می‌شود.
- PWA روی گوشی فقط روی **HTTPS** نصب‌شدنی است.

## نصب روی گوشی

- **iOS:** سایت را در Safari باز کن ← Share ← «Add to Home Screen».
- **اندروید (PWA):** در Chrome منوی سه‌نقطه ← «Install app».
- **اندروید (اپ با اسکن کامل حافظه):**

  ```bash
  cd frontend
  npm run build && npx cap sync android
  npx cap open android     # در Android Studio: Build ← Build APK
  ```

  در اولین اجرا آدرس سرور را در صفحه‌ی ورود وارد کن. نیاز به Android Studio و JDK 21 دارد.

## ساختار

```
backend/   Laravel: app/Services/Telegram (MadelineProto، همگام‌سازی)، TrackCache، LyricsService، کنترلرهای API
frontend/  Vue: stores/player.ts (صف، شافل، تکرار، Media Session)، stores/jam.ts (پخش گروهی)، stores/library.ts (کاتالوگ آفلاین و جستجو)،
           stores/downloads.ts، stores/local.ts (آهنگ‌های دستگاه)، android/ (پروژه‌ی Capacitor + LocalMusicPlugin)
docker/    Caddyfile، php.ini، entrypoint
```

## اپ اندروید

نسخه‌ی آماده در [Releases گیت‌هاب](https://github.com/hosseinganji/harmuny/releases/latest) است (`harmony.apk`). اپ خودش به `harmony-musics.ir` وصل می‌شود و وقتی نسخه‌ی جدید بیاید، در منوی پروفایل دکمه‌ی به‌روزرسانی نشان می‌دهد.

با صفحه‌ی خاموش هم پخش ادامه پیدا می‌کند: یک سرویس پخش اندروید (`PlaybackService.java`) تا وقتی آهنگ پخش می‌شود CPU و Wi‑Fi را بیدار نگه می‌دارد. نوتیفیکیشن پخش و کنترل از صفحه‌ی قفل، هدفون، بلوتوث و ماشین هم از همین سرویس می‌آیند.

ساختن APK به JDK 21 و Android SDK (در `~/Android`) نیاز دارد:
`JAVA_HOME=~/Android/jdk ANDROID_HOME=~/Android/Sdk npm run android:apk`
کلید امضا بیرون از مخزن است (`~/Android/harmony-release.jks` و `harmony-release.properties`). از آن نسخه‌ی پشتیبان نگه دار: بدون همین کلید، نسخه‌های بعدی روی اپ نصب‌شده نصب نمی‌شوند.

## محدودیت‌ها

- iOS به وب‌اپ‌ها اجازه‌ی اسکن حافظه نمی‌دهد؛ آهنگ‌ها باید از برنامه‌ی Files انتخاب شوند (داخل برنامه کپی می‌شوند).
- حجم دانلود آفلاین به سهمیه‌ی مرورگر بستگی دارد (روی iOS محدودتر است). برنامه درخواست «ذخیره‌سازی دائمی» می‌دهد.
- اتصال تلگرام با حساب کاربری انجام می‌شود (نه ربات)؛ از یک حساب جداگانه یا حساب خودت با احتیاط استفاده کن.
- پخش در پس‌زمینه در PWA معمولاً کار می‌کند، اما سیستم‌عامل ممکن است برنامه‌ی متوقف‌شده را ببندد.
